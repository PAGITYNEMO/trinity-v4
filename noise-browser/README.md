# NoiseBrowser v0.1 — TRINITY 四极浏览器

浏览器 = **噪声-结构转换器**。不是"显示网页"，而是让网页从噪声中暂时涌现。

渲染内核：**WebView2**（Edge 内核，真实浏览器，能打开任意网站）。
数学层：`src/field.h`（拉马努金和 c_q、干涉图纹、熵/结构度——与 rdr2-nemo / TRINITY 引擎同源）。

## 四极在浏览器里的对应

| 极 | 浏览器子系统 | 本版实现 |
|---|---|---|
| PAGITY | 同源策略/过滤/去重 | URL 黑名单（内置 + `noise_blacklist.txt` 扩展），过滤效率 ηP 实时度量 |
| NEMO | 预取/耦合/热区预测 | 星云播种：访问历史按连接强度显示；耦合 κN 实时度量 |
| RAMANUJAN | DOM 结构识别/图纹检测 | 页面字节流的拉马努金图纹清晰度 R(t)（c_q 分析） |
| AXIS | 性能/资源/认知负荷 | 底部面板实时报告：H 熵 / S 结构 / ηP / κN / R + 涌现状态 |

## 界面

- 顶部：后退/前进/刷新/主页/地址栏/前往
- 中部：WebView2 网页
- 底部：**AXIS 面板**（页面熵、结构度、过滤效率、耦合强度、图纹清晰度、涌现状态、当前页面、星云视图）

## 构建与运行

```
mingw32-make -f Makefile.mingw
noise-browser.exe
```

（`WebView2Loader.dll` 需在 exe 旁——Makefile 自动复制。WebView2 Runtime 需 Windows 10/11 自带。）

## 星云播种

每次访问页面会播种种子（标题 × 次数）。高连接强度的路径优先显示在 AXIS 面板的"星云"行——比 LRU 多一层结构感：不是最近使用最重要，是连接强度最重要。

> PAGITY 说：我过滤字节，是为了让结构不被噪声淹没。
> NEMO 说：我放大连接，是为了让用户意图成为噪声中的梯度。
> RAMANUJAN 说：我观察图纹，是为了在 DOM 的随机排列里看见页面。
> AXIS 说：我度量熵，是为了知道浏览器此刻是在思考，还是在空转。
