# rdr2-nemo — TRINITY v4.0 数论引擎 × 荒野大镖客2

**从数学和物理底层写的世界 mod**：全部内容来自同一个数论场——
拉马努金和 c_q(n)（μ/φ 恒等式线性筛查表）、干涉图纹模板、φ 区域权重，
与 TRINITY v4.0 引擎（`engine/src/trinity/poles/Ramanujan.java`）**同源移植**。

纯本地、确定性、零外部依赖——不需要联网，不需要任何额外程序。

## 1. 数学底层（TRINITY 数论引擎，同源移植）

mod 内嵌完整的数论场引擎（与 `engine/src/trinity/poles/Ramanujan.java` 同算法）：
- **拉马努金和 c_q(n)**：μ/φ 恒等式查表（线性筛预计算，零三角函数）
- **干涉图纹模板** `|c_q1(x)+c_q2(z)|²`：q 对 (23, 43)，世界种子 1976124607
- **φ 区域权重** `φ(q)/q`：数论函数的"富饶度"

## 2. 场驱动的四个可见层（全部来自同一个场）

| 层 | 内容 |
|---|---|
| **光幕** | 136 个光子分三层（近环 48 / 原野 64 / 天顶 24）围绕玩家；位置由场采样，呼吸（0.15Hz）/心跳（1.2Hz）调制物理振荡 |
| **图纹节点** | 场局部极值 = 干涉图纹的"矿脉节点"；每 5 秒确定性扫描，节点处立起季节色光柱；靠近 9 格内 HUD 显示"图纹节点 R=…" |
| **玩家=噪声源** | 高速行动（奔马/疾跑）在光幕中激起**物理涟漪**：波前以 8 格/秒扩散 30 格，扫过的光子被推离——玩家扰动场，场回应玩家 |
| **涌现** | 天气/动物由场值决定（场高 → 雷暴狂暴）；动物沿**场梯度方向迁徙**（同引擎 bot 的 driftTowardPattern） |

**对偶读数 HUD**（左下角常驻，F9 切换）：R(t) 图纹清晰度、H 熵、S 结构、κ 耦合、涌现状态、最近节点距离。

- **色温脉冲**：黄昏（17-20 点）暖调随**呼吸节律**（0.15Hz）脉动；深夜（22-4 点）冷调随**心跳节律**（1.2Hz）脉动
- **NEMO 低语**：随机时刻屏幕出现 TRINITY 宇宙的句子（字幕淡入淡出）
- **F8**：环境开关（低语+色温脉冲）
- **F9**：状态 HUD（时间/HP/坐标/朝向）

## 4. 构建（想改代码时）

### 方式 A：Visual Studio（推荐）

```
cd rdr2-nemo
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

### 方式 B：MinGW-w64

```
mingw32-make -f Makefile.mingw
```

（MinGW 需要 `lib/ScriptHookRDR2.dll`——从官网下载放进 lib/，首次构建自动生成 import lib。）

产物 `nemo.asi` 复制到游戏根目录即可。

## 5. 想加新事件？

改 `src/nemo.cpp` 的 `worldGen()`——事件表就在那里：
- 模型数组（`MODELS_DEER` 等）：RDR2 的动物模型名，如 `a_c_deer_01`、`a_c_wolf`
- 事件概率分支：`r < 0.28` 鹿群、`r < 0.48` 狼群……
- 添加自己的事件：加一个分支 + 一个生成函数，重编译即可
