# rdr2-nemo

TRINITY v4.0 世界观 × Red Dead Redemption 2 单机 mod（ScriptHookRDR2, C++）。

- **NEMO 环境**：呼吸/心跳节律驱动的色温脉冲 + NEMO 低语字幕
- **线上内容桥**：在单机生成线上风格的模型/武器/跟班（hash 可配置）
- **AI 连接口**：本地 HTTP 服务器（127.0.0.1:43072），AI agent 实时读写游戏

构建与玩法详见 [`README-玩.md`](README-玩.md)。

> 仅供离线单机使用。ScriptHookRDR2 运行时请从 dev-c.com 官网获取。
